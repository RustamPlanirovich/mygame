## 📋 Обзор

Система анализа контрактов - это механика "Factorio-lite", которая помогает игрокам планировать выполнение контрактов. Система автоматически рассчитывает:
- Успеет ли игрок выполнить контракт вовремя
- Какой ресурс является узким местом
- Сколько времени осталось до готовности
- Даёт умные подсказки по оптимизации

### Ключевые особенности:
- 🎯 **ETA (время до готовности)** - для каждого ресурса
- ⚡ **Бонус за скорость** - +50% наград если выполнен быстрее половины времени
- 🎨 **Визуальные прогресс-бары** - для каждого ресурса
- 💡 **Умные подсказки** - что делать если не успеваешь
- 🟢 **Цветовая индикация** - зелёный/жёлтый/красный статус

## 📊 Типы данных

### ContractResourceAnalysis

Анализ одного ресурса в контракте:

```typescript
interface ContractResourceAnalysis {
  resource: ResourceType;    // Тип ресурса
  needed: Decimal;           // Сколько всего нужно
  current: Decimal;          // Сколько сейчас есть
  remaining: Decimal;        // Сколько ещё нужно
  production: Decimal;       // Производство в секунду
  etaSeconds: number;        // Секунд до готовности (может быть Infinity)
  willComplete: boolean;     // Успеет ли к дедлайну
  isBottleneck: boolean;     // Это узкое место?
}
```

### ContractAnalysis

Общий анализ контракта:

```typescript
interface ContractAnalysis {
  perResource: ContractResourceAnalysis[];  // Анализ каждого ресурса
  overallStatus: 'ready' | 'on_track' | 'at_risk' | 'will_fail';
  criticalResource: ResourceType | null;    // Самый проблемный ресурс
  suggestion: string;                        // Подсказка игроку
  timeToComplete: number;                    // Секунд до полного выполнения
  speedBonus: boolean;                       // Получит ли бонус за скорость
}
```

### Contract (расширенный)

```typescript
interface Contract {
  id: string;
  title: string;
  description: string;
  requirements: Partial<Record<ResourceType, Decimal>>;
  rewards: {
    credits?: Decimal;
    researchPoints?: Decimal;
    influence?: Decimal;
  };
  // Новые поля:
  speedBonus?: {                             // Бонус за быстрое выполнение
    credits?: Decimal;
    researchPoints?: Decimal;
    influence?: Decimal;
  };
  acceptedAt: number;                        // Время принятия контракта
  expiresAt: number;                         // Время истечения
  tier: 'easy' | 'medium' | 'hard' | 'epic';
  analysis?: ContractAnalysis;               // Расчётные данные (не сохраняется)
}
```

## 🔧 Основные функции

### analyzeContract()

Главная функция анализа:

```typescript
function analyzeContract(
  contract: Contract,
  state: GameState
): ContractAnalysis
```

**Алгоритм:**
1. Вычисляет текущее количество каждого ресурса
2. Вычисляет производство в секунду
3. Рассчитывает ETA: `remaining / production`
4. Сравнивает ETA с временем до дедлайна
5. Определяет общий статус (ready/on_track/at_risk/will_fail)
6. Генерирует подсказку
7. Проверяет возможность получить бонус за скорость

**Статусы:**
- `ready` - Все ресурсы готовы, можно сдавать
- `on_track` - ETA < 50% времени до дедлайна
- `at_risk` - ETA < 100% времени до дедлайна (впритык)
- `will_fail` - ETA > время до дедлайна

### generateSuggestion()

```typescript
function generateSuggestion(
  perResource: ContractResourceAnalysis[],
```

**Примеры подсказок:**
- ✅ "Все ресурсы готовы! Можете сдать контракт прямо сейчас."
- 🟢 "Всё идёт по плану. Контракт будет выполнен вовремя."
- ⚠️ "Узкое место: Железо. Нужно увеличить производство на 25/сек."
- ❌ "Не успеете! Медь: нужно увеличить производство на 150%."
- ❌ "Железо не производится! Постройте производящие здания."

## 📈 Формулы и расчёты

### ETA (Estimated Time to Arrival)

```
ETA = remaining / production

Где:
- remaining = needed - current
- production = производство в секунду
- ETA = секунд до готовности
```

**Особые случаи:**
- Если `production <= 0` → ETA = ∞ (бесконечность)
- Если `remaining <= 0` → ETA = 0 (уже готово)

### Определение статуса

```
if (timeToComplete === 0)           → 'ready'
if (timeToComplete < timeLeft * 0.5) → 'on_track'
if (timeToComplete < timeLeft)      → 'at_risk'
else                                → 'will_fail'
```

### Бонус за скорость

```
speedBonus = (timeTaken < totalTime * 0.5)

Где:
- timeTaken = now - acceptedAt
- totalTime = expiresAt - acceptedAt

Если speedBonus = true → +50% ко всем наградам
```

## 🎯 Примеры использования

### Пример 1: Успешное выполнение с бонусом

```
Контракт:
- Требование: 1000 ore
- Таймер: 5 минут
- Текущее производство: 10 ore/сек

Расчёт:
- Нужно ещё: 1000 ore
- Время до готовности: 1000 / 10 = 100 сек = 1.67 минуты
- Статус: 'on_track' (1.67 < 2.5 минут)
- Бонус за скорость: ДА (если сдать сейчас)

Подсказка: "Всё идёт по плану. Контракт будет выполнен вовремя."
```

### Пример 2: Узкое место

```
Контракт:
- ore: 500 (есть 450, производство 5/сек) → ETA: 10 сек
- steel: 200 (есть 50, производство 1/сек) → ETA: 150 сек
- Таймер: 120 секунд

Анализ:
- ore: будет готов вовремя ✅
- steel: НЕ успеет ❌ (нужно 150 сек, есть 120)
- Статус: 'will_fail'
- Критический ресурс: steel

Подсказка: "Не успеете! Steel: нужно увеличить производство на 25%."
```
