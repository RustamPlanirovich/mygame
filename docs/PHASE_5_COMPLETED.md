## 🎮 Как Использовать

### Для Игроков

1. **Достигните 3+ Ascension** чтобы разблокировать процедурные галактики
2. Откройте панель "Карта Галактик" (🌌)
3. Прокрутите вниз до раздела "Процедурные Галактики"
4. Нажмите кнопку "Генерировать" (стоит кредиты)
5. Нажмите "Исследовать галактику" чтобы открыть её свойства
6. Получите награды и продолжайте генерировать новые галактики!

### Для Разработчиков

```typescript
// Генерация новой галактики
gameStore.generateProceduralGalaxy();

// Исследование галактики
gameStore.exploreProceduralGalaxy(8);

// Получение галактик
const galaxies = gameStore.proceduralGalaxies.galaxies;

// Проверка разблокировки
const unlocked = gameStore.ascension.unlocks.proceduralGalaxies;
```
