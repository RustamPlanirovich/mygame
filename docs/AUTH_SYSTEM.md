# Система авторизации

## Обзор

Добавлена простая система регистрации и входа пользователей. Сохранения игры теперь привязаны к аккаунту пользователя.

## Реализованные функции

### Backend

1. **Таблица пользователей** (`users`)
   - `id` - уникальный ID пользователя
   - `email` - email (уникальный)
   - `password` - пароль (хранится в открытом виде, без хеширования)
   - `created_at` - дата создания

2. **Обновленная таблица сохранений** (`game_save`)
   - Добавлено поле `user_id` с внешним ключом на `users(id)`
   - При удалении пользователя его сохранения удаляются автоматически (CASCADE)

3. **API эндпоинты**

   **POST /api/auth/register** - Регистрация
   ```json
   Request:
   {
     "email": "user@example.com",
     "password": "password123"
   }
   
   Response (успех):
   {
     "ok": true,
     "user": {
       "id": 1,
       "email": "user@example.com"
     }
   }
   
   Response (ошибка):
   {
     "ok": false,
     "error": "USER_EXISTS" | "EMAIL_AND_PASSWORD_REQUIRED"
   }
   ```

   **POST /api/auth/login** - Вход
   ```json
   Request:
   {
     "email": "user@example.com",
     "password": "password123"
   }
   
   Response (успех):
   {
     "ok": true,
     "user": {
       "id": 1,
       "email": "user@example.com"
     }
   }
   
   Response (ошибка):
   {
     "ok": false,
     "error": "INVALID_CREDENTIALS" | "EMAIL_AND_PASSWORD_REQUIRED"
   }
   ```

4. **Обновленные эндпоинты сохранений**
   - Теперь все эндпоинты сохранений (`GET/PUT/DELETE /api/save`) требуют header `x-user-id`
   - Сохранения изолированы по пользователям

### Frontend

1. **Компонент AuthForm**
   - Форма входа/регистрации
   - Переключение между режимами
   - Обработка ошибок с переводом на русский

2. **Интеграция в App.tsx**
   - Проверка авторизации при загрузке
   - Блокировка доступа к игре до входа
   - Отображение email пользователя и кнопка выхода
   - Автоматическая загрузка сохранения после входа

3. **Обновлен gameStore**
   - `saveGame()` отправляет `x-user-id` в заголовках
   - `loadGame()` загружает сохранение пользователя
   - Данные пользователя хранятся в localStorage

## Использование

1. При первом запуске появится форма регистрации
2. Введите email и пароль, нажмите "Зарегистрироваться"
3. После успешной регистрации автоматически произойдет вход
4. Ваш прогресс теперь сохраняется на сервере, привязанный к вашему аккаунту
5. При следующем визите используйте форму входа с теми же данными

## Безопасность

⚠️ **ВАЖНО**: Текущая реализация не включает:
- Хеширование паролей (пароли хранятся в открытом виде)
- Токены/сессии (используется простой header `x-user-id`)
- Проверку email
- Rate limiting
- HTTPS

Эта реализация подходит только для разработки и тестирования. 
Для production необходимо добавить:
- Хеширование паролей (bcrypt)
- JWT токены или сессии
- Валидацию email
- HTTPS
- Rate limiting для защиты от brute-force атак
