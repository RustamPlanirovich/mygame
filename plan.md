PROTOCOL: YGGDRASIL — Master Game Design Document

Версия: 1.0
Жанр: Hardcore Idle / Incremental / Automation / Tower Defense Strategy
Сеттинг: Киберпанк-космос.
Платформа: Web (HTML5/Canvas).

1. Сюжет и Концепция

Предыстория

Ты — ИИ класса "Архитектор", пробудившийся на орбитальной мегаструктуре "Иггдрасиль" спустя тысячи лет после неизвестной катастрофы. Твои банки памяти повреждены, системы обесточены. Вокруг — руины цивилизации и агрессивный "Цифровой Шум" (Глитчи), пытающийся поглотить остатки данных.

Твоя цель: Восстановить станции, построить флот, защитить сектор и достичь Технологической Сингулярности (Престиж).

Сценарий Игры (Player Journey)

Акт 1: Пробуждение (0 - 1 час игры)

Состояние: Экран черный. Работает только аварийная консоль.

Действие: Ручной запуск генератора (клики).

Цель: Накопить 100 Энергии для запуска авто-майнера.

Ощущение: Одиночество, борьба за каждый ватт.

Акт 2: Индустриализация (1 - 24 часа)

Состояние: База оживает. Гудят заводы, летают дроны.

Действие: Открытие переработки (Лед -> Вода, Руда -> Сплавы). Игрок сталкивается с нехваткой места на складах.

Конфликт: Первые атаки Глитчей. Игрок учится балансировать энергию между Заводами и Турелями.

Акт 3: Экспансия (24+ часа)

Состояние: Выход на галактическую карту.

Действие: Строительство кораблей. Экспедиции за редкими артефактами. Торговля на бирже.

Угроза: Массированные атаки боссов.

Финал: Достижение лимита вычислений. Необходимость "Квантового Сброса" (Престиж).

Примечание по новым референсам (Industry Idle, Cell: Idle Factory Incremental)

С этого момента базовая фантазия сохраняется (орбитальная мегаструктура, восстановление, киберпанк-космос), но основной «игровой язык» меняется:

- Игра = фабрика на сетке (клетки/тайлы), где игрок строит производственные цепочки.
- Управление = выбор клетки → инспектор/панель действий, как в Cell.
- Прогресс = расширение территории (новые клетки), рост throughput (ед/сек), апгрейды, исследования, престиж.

2. Геймплейный Цикл (Core Loop)

Осмотр (Inspect): Игрок выбирает клетку на сетке и смотрит «что здесь происходит» (производство/потребление/запасы/узкие места).

Строительство (Build): Размещение на клетках добытчиков/конвейеров/процессоров/складов и их апгрейд.

Потоки (Route): Настройка перемещения ресурсов между соседними клетками (простая логистика «из A в B» для MVP).

Баланс (Optimize): Подгонка соотношений (rates) — чтобы входы/выходы цепочек сходились и не было простоя.

Экономика (Trade): Продажа/покупка на рынке для сглаживания дефицитов и ускорения прогресса.

Угроза (Defend): Волны «Шума» давят на экономику (штрафы/атаки/перегрузка) и вынуждают держать оборону.

Развитие (Research): Системные апгрейды, открывающие новые здания, ускорения и качество логистики.

Престиж (Reboot): Квантовый сброс ради мета-валюты (Кубиты) и постоянных бонусов.

4. Ключевые Механики

4.0. Сетка и клетки (новый базис)

- Мир — прямоугольная сетка клеток (тайлов). Каждая клетка либо пустая, либо содержит здание.
- Игрок взаимодействует через паттерн «выбрал клетку → открыл инспектор → действие» (как в Cell).
- Здания работают в тиках симуляции и производят/потребляют ресурсы.
- Логистика в MVP — маршруты только между соседними клетками (без сложных лент/сплиттеров). Усложнение — позднее.

4.1. Галактическая Биржа

Цены на ресурсы меняются каждые 30 секунд.

Волатильность: События ("Война", "Дефицит") могут поднять цену на 300% или обвалить её.

Стратегия: Игрок не продает всё сразу, а копит, ожидая пика цены.

4.2. ИИ-Демоны (Managers)

Вместо покупки постоянных "менеджеров", игрок арендует программы за ежесекундный расход Энергии.

Smart-Broker: Авто-продажа ресурсов при выгодном курсе. (Цена: 50 E/сек).

Overclocker: Ускоряет заводы на 200%, но греет систему. (Цена: 500 E/сек).

Oracle: Подсвечивает самое выгодное здание для покупки (ROI).

4.3. Нано-Рой (Распределяемая мощность)

Игрок управляет ползунками (слайдерами), распределяя общий пул наноботов:

🔴 Атака: Наносят урон врагам.

🟢 Ремонт: Чинят щит базы.

🔵 Буст: Ускоряют производство.

- [x] Реализовано (MVP): распределение attack/repair/boost + эффекты в тике + UI.
  - Код: src/core/constants/nanoSwarm.ts, src/features/gameStore.ts
  - UI: src/components/game/CombatPanel.tsx

4.4. Конструктор Кораблей

Корабли собираются из модулей для Экспедиций:

Корпус: Определяет HP корабля.

Двигатель: Определяет скорость полета.

Трюм: Определяет, сколько лута привезет.

- [x] Реализовано (MVP): модули hull/engine/cargo + Mk.II апгрейды + влияние на экспедиции.
  - Код: src/core/constants/ship.ts, src/features/gameStore.ts
  - UI: src/components/game/ExpeditionPanel.tsx

4.5. Инспектор клетки (UX-ядро, как в Cell)

- Заголовок: название здания/клетки, уровень, статус (работает/простой/нет ресурсов).
- Блок «In/Out»: входные и выходные потоки (ед/сек) + буферы.
- Кнопки: Улучшить, Пауза, Снести, Настроить маршрут (для логистических зданий).
- Подсказка причины простоя (самая частая проблема фабрик).

5. Деревья Развития (Tech Trees)

Система прокачки разделена на 5 независимых сущностей.

5.1. СИСТЕМНОЕ ЯДРО (System Kernel)

Главное дерево игрока. Валюта: Данные.

Ветка: CPU (Скорость)

Multithreading: Ускоряет все игровые таймеры на 1%.

Overclock: Активная способность "Ускорение времени".

Ветка: RAM (Память)

Compression: Увеличивает вместимость складов.

Virtualization: Позволяет запускать больше Демонов одновременно.

Ветка: I/O (Торговля)

High-Frequency Trading: Снижает комиссию биржи.

5.2. ПРОИЗВОДСТВЕННАЯ МАТРИЦА (Production Matrix)

Дерево заводов. Валюта: Чертежи (из экспедиций).

Ветка: Синтез

Molecular Stability: Шанс х2 продукции (Double craft).

Ветка: Термодинамика

  - Код: src/core/constants/productionMatrix.ts, src/features/gameStore.ts

Ветка: Логистика

5.3. ПРОТОКОЛ "ЭГИДА" (Aegis Protocol)

6. Техническая Реализация (Data Structure)

Пример того, как мы будем хранить данные в коде (JSON).

Новый фундамент (для фабрики на сетке)

- Tile/Grid: карта хранит здания по координатам.
- BuildingInstance: у здания есть уровень, буфер(ы), состояние, подключенные маршруты.
- SimulationTick: детерминированный шаг симуляции (например, 10–20 тиков/сек в UI, но с возможностью «агрегации» при офлайне).
- Rates-first: все процессы описываем через скорости, чтобы быстро считать производство.

7. План Разработки (Roadmap)

Фаза 1: MVP (Cell-подобный UX + фабрика на сетке)

[x] Сетка (карта) + выбор клетки + инспектор клетки.

[x] 3–5 зданий для первой цепочки:
  - Генератор (даёт Энергию)
  - Добытчик (даёт 1 сырьё: например, Руда)
  - Плавильня/Процессор (сырьё → сплав)
  - Склад (буфер, лимиты)
  - Линк/Конвейер (простой маршрут «из A в B» между соседями)

[x] Симуляция тиков: производство/потребление/буферы/простои.

[x] Сохранение прогресса в локальную БД Postgres через локальный API (без LocalStorage).

[x] UX линий и диагностика узких мест: подсветка линий при наведении, выбор линии, удаление ПКМ/кнопкой/клавишей, подсветка проблемных переработчиков.

[x] Диагностика выбранной линии: throughput за тик, причина нуля/упора в лимит, подсказка «что кормит источник» на 1 шаг назад.

[x] Контекст выбранной линии в инспекторе клетки: источник/цель, локальные запасы, должен ли тайл производить/потреблять ресурс, подсказка блокировки.

Фаза 2: Экономика (производственные цепочки + рынок)

[x] Добавление ресурсов T0–T2 (Лед/Руда/Углерод → Сталь и т.п.).

[x] Нормальные лимиты хранилищ + отображение переполнения в инспекторе.

[x] Рынок/биржа (упрощённо): цены тикают раз в N секунд, кнопки купить/продать из складов.

Фаза 3: Угроза (атаки, как давление на фабрику)

[x] Волны «Глитчей» как периодический эвент.

[x] Турели/щит как здания на клетках.

[x] Энергопитание обороны (турели тратят энергию при стрельбе → конфликт с производством) + UI: расход ⚡/с и эффективность.

[x] Давление врагов: непрерывный урон при приближении + телеметрия в UI (текущее/потенциальное).

Фаза 4: Глубина (деревья, демоны, престиж)

[x] 5 деревьев прокачки (минимальные ветки для MVP-эффекта: скорость, буферы, торговля).

[x] Престиж (Кубиты) + 2–3 мета-апгрейда.

[x] Экспедиции/флот — только после стабилизации фабричного ядра.
