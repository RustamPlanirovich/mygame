## Текущая реализация в проекте

### Компоновка

- Верх: одна строка 34px (`TopBar`) — валюты, энергобаланс, экология, закреплённые
  ресурсы со скоростью, активные предупреждения, справа склад/сводка/меню.
- Центр: поле (PixiJS) во всю оставшуюся площадь.
- Слева на карте: быстрая панель разделов (`QuickRail`), внизу слева — мини-карта.
- Справа: панель управления (`SidePanel`) поверх карты, один раздел за раз;
  крестик закрывает её и снимает выбор клетки, Escape — то же (сначала снимает
  режим строительства).

### Верхняя строка ресурсов (Pinning + Warehouse)

- В верхней строке показываются только закреплённые ресурсы: запас + скорость (`+0.00`).
- Кнопка «Склад» открывает список всех ресурсов.
- В «Складе» можно закреплять/откреплять ресурсы (pinning). Закрепления хранятся на сервере.

### Строительство (`BuildPanel`)

- Один плоский список с поиском по названию/ресурсу вместо колоды карточек.
- В строке: флажок «строим этим», название, **модификатор клетки**, счётчик построенных,
  вход (`→|`), выход (`|→`) и стоимость справа.
- Модификатор клетки — реальный множитель близости (`proximityRules`) для выбранной
  клетки, тот же, что применяет тик. Переключатель «только положительные модификаторы»
  оставляет в списке лишь то, что здесь получает бонус.
- Клик по пустой клетке открывает строительство для неё; клик по строке ставит здание
  сразу, если клетка подходит, иначе включает режим строительства.

### Управление сеткой

- Колесо мыши: зум.
- Space + drag или средняя кнопка мыши: панорамирование.

#### Автозум / автоподгон (fill)

- Пока игрок не взаимодействовал с камерой вручную (зум/пан), камера автоматически подбирает масштаб и центрирует сетку, чтобы она занимала максимум доступного места.
- После первого ручного взаимодействия камера сохраняет выбранный вид и больше не “перетягивает” масштаб при ресайзе/изменениях.

### Месторождения (Deposits)

- Ресурсы добываются не с любой клетки.
- На пустых клетках есть редкие месторождения: `ore` / `ice` / `carbon` (на сетке помечаются как `Fe` / `Ice` / `C`).
- Добывающие здания можно ставить только на соответствующие месторождения:
	- `miner_mk1` → `ore`
	- `ice_extractor_mk1` → `ice`
	- `carbon_harvester_mk1` → `carbon`

### Логистика (Links)

- Линии можно ставить в режим **паузы** (enabled=false) — перенос по такой линии не выполняется.
- Визуально отключённые линии отображаются более тускло.

### Инспектор: Политика рынка (fallback)

- В инспекторе клетки есть блок **«Политика рынка (fallback)»** для tradeable ресурсов (`ore/ice/carbon/steel`).
- **ИМП**: если клетке не хватает входного ресурса для работы, игра пытается докупить небольшую порцию на рынке (за ⚡, с учётом маржи).
- **ЭКС**: если на клетке есть излишки, игра пытается автопродать небольшую порцию на рынке (в ⚡, с учётом маржи).

### Рынок: Терминал (MVP)

- Вкладка рынка оформлена как терминал: слева список ресурсов, справа выбранный ресурс.
- Показаны цены **купить/продать** (учёт маржи) и простой график цены по `market.history`.
- Есть форма заявки с количеством и действия **Купить/Продать**.

### Расширение сетки по прогрессу

- Добавлен апгрейд исследований **«Сектор: Расширение»**.
- Каждый уровень увеличивает размер сетки фабрики на **+2×2 клетки**.
- Новые клетки получают месторождения по тем же шансам; существующие месторождения не перегенерируются.

1. Общая компоновка (Layout)
Интерфейс Industry Idle адаптивный, но классическая десктопная версия строится по схеме "Dashboard" (Приборная панель).

Верхняя панель (Header): Глобальные ресурсы и статус.

Центральная область (Viewport): Игровое поле (сетка).

Нижняя панель (Footer/Dock): Меню строительства и инструментов.

Боковые/Всплывающие окна (Modals/Sidebars): Рынок, исследования, статистика.

2. Верхняя панель (Global Resource Bar)
Это "пульс" игры. Игрок смотрит сюда, чтобы понять, что у него в дефиците.

Валюта: Самый левый или самый крупный элемент. Обычно отображается "Cash" (Наличные) и "Net Worth" (Общая стоимость активов).

Особенность: Динамическое изменение цвета (зеленый/красный) при изменении баланса в реальном времени.

Стратегические ресурсы: Энергия (Power), Топливо, Рабочая сила, Вычислительная мощность.

Отображается в формате: Текущее количество (+Производство/сек).

Пример: ⚡ 5.4k (+120/s).

Группировка ресурсов: Так как ресурсов сотни, они не показываются все сразу.

Используются Pinning (Закрепление): Игрок может сам выбрать 5-10 ресурсов, которые хочет видеть в хедере.

Остальные скрыты в выпадающем меню "Склад" (Warehouse).

Кнопки управления временем/состоянием: Пауза, настройки, сохранение.

3. Центральная область (Grid / Game World)
Это "холст", где происходит действие.

Сетка (Grid):

Используется 2D-сетка (тайловая система).

Каждый тайл — это объект данных: coordinate {x, y}, terrainType, buildingID.

Визуализация зданий:

Здания занимают 1x1, 2x2 или более клеток.

Важен Overlay (Слой поверх): Иконки над зданиями, показывающие статус (нет энергии, склад полон, нет сырья).

Интерактивность:

Клик (Left Click): Открывает детальное меню здания.

Drag & Drop: Перемещение карты.

Zoom: Колесико мыши масштабирует сетку (от "вид из космоса" до конкретного завода).

Соединения: В Industry Idle важна логистика. Дороги и конвейеры рисуются автоматически или вручную, соединяя тайлы. Линии должны быть четко видны.

4. Нижняя панель (Build Menu)
Основной инструмент взаимодействия.

Категоризация (Табы): Здания разбиты по типам:

⛏️ Добыча (Mining)

🏭 Фабрики (Factories)

💡 Энергия (Power)

🚚 Логистика (Logistics)

🔬 Лаборатории (Labs)

Карточка здания (Building Card):

Внутри меню каждое здание — это кнопка.

Hover Effect (Наведение): При наведении всплывает Tooltip с критической информацией:

Стоимость постройки.

Вход (Input): 2 Iron Ore.

Выход (Output): 1 Iron Plate.

Потребление энергии.

Quick Actions: Кнопки для сноса (Bulldoze), улучшения (Upgrade), копирования настроек.

5. Детальные окна (Modals & Inspectors)
Самая сложная часть разработки, так как здесь происходит микроменеджмент.

А. Инспектор здания (При клике на постройку)
Появляется сбоку или как модальное окно.

Название и Уровень.

Тумблер ВКЛ/ВЫКЛ.

Слайдеры производства: Возможность ограничить производство или потребление.

Логистика:

Настройка импорта (откуда брать ресурсы: с рынка или с соседних клеток).

Настройка экспорта (продавать автоматически или хранить).

Рецепты: Если завод может делать разные вещи (например, Химический завод), здесь должен быть Dropdown (выпадающий список) выбора рецепта.

Б. Торговый терминал (Marketplace)
Industry Idle — это экономическая игра. Интерфейс рынка напоминает биржевой терминал.

Список ресурсов: Слева с возможностью поиска.

График цены (Chart): Line chart (линейный график) изменения цены за последние 24ч/неделю.

Стакан (Order Book): Предложения игроков (Купить/Продать).

Форма заявки:

Поле "Цена" (Price).

Поле "Количество" (Quantity).

Итоговая сумма.

В. Дерево технологий (Tech Tree)
Граф (Node Graph): Узлы, соединенные линиями зависимостей.

Цветовое кодирование:

Зеленый: Изучено.

Желтый: Доступно для изучения.

Серый: Заблокировано.

Стоимость отображается в "Очках науки" (Science Packs).

6. UX-фишки для разработчика
Если ты будешь это реализовывать (например, на стеке Vue/React или чистом JS):

Визуальная чистота: Используй плоский дизайн (Flat Design). Иконки (SVG) лучше, чем сложные спрайты. Шрифт должен быть моноширинным (Monospace) для цифр, чтобы они не "прыгали" при обновлении.

Цветовая кодировка цифр:

Зеленый: Доход / Профицит.

Красный: Расход / Дефицит.

Оранжевый/Желтый: Предупреждение (склад почти полон).

Toasts (Всплывающие уведомления): "Исследование завершено", "Новое достижение". Они должны появляться в углу и исчезать, не блокируя игру.

Tooltip — это король: Игрок не должен гадать, что делает иконка. Абсолютно на всем при наведении должна быть подсказка.

Технический совет по реализации
Сетка (Grid): Для веб-игры лучше всего использовать HTML5 Canvas (библиотеки вроде PixiJS или Phaser) для отрисовки карты, если объектов > 1000. Если карта маленькая — можно обойтись CSS Grid или просто div с абсолютным позиционированием.

UI Слой: Интерфейс (кнопки, меню) делай отдельным слоем поверх Canvas через обычный HTML/CSS (React/Vue), так как верстать сложные меню внутри Canvas — это боль.
