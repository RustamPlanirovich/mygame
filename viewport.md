Для реализации такой механики (как в Industry Idle, Factorio или Miro) используется концепция **"Виртуальной камеры" (Viewport)**.

Ты не двигаешь тысячи клеточек по отдельности. Ты двигаешь "мир" (или камеру над миром).

Вот алгоритм и логика реализации, разбитая на компоненты.

### 1. Базовые переменные (State)

Тебе нужно хранить состояние твоей "Камеры":

```javascript
const state = {
  scale: 1.0,        // Текущий зум (1.0 = 100%)
  offsetX: 0,        // Смещение камеры по X в пикселях
  offsetY: 0,        // Смещение камеры по Y в пикселях
  isDragging: false, // Зажата ли мышка
  lastMouseX: 0,     // Последняя позиция мыши для расчета дельты
  lastMouseY: 0
};

// Константы размеров
const TILE_SIZE = 40; // Базовый размер клетки (например, 40px ~ 1см)
const MIN_ZOOM = 1.0; // Минимальный размер (1x1 см)
const MAX_ZOOM = 3.0; // Максимальный размер (3x3 см)

```

### 2. Логика Перетаскивания (Panning)

Здесь используется стандартная Drag&Drop логика. Мы меняем `offsetX` и `offsetY` всего контейнера с сеткой.

* **MouseDown:** Игрок нажал кнопку. Фиксируем `isDragging = true` и запоминаем координаты мыши.
* **MouseMove:** Если `isDragging` истинно:
1. Считаем разницу: `deltaX = currentMouseX - lastMouseX`.
2. Прибавляем разницу к смещению мира: `state.offsetX += deltaX`.
3. Обновляем `lastMouseX`.
4. Перерисовываем мир с новым смещением.


* **MouseUp:** `isDragging = false`.

### 3. Логика Масштабирования (Zooming)

Это самое хитрое. Когда пользователь крутит колесико, клетка должна увеличиваться/уменьшаться.

* **Событие:** `wheel`.
* **Расчет:**
```javascript
handleZoom(event) {
    event.preventDefault(); // Чтобы страница не скроллилась

    // Опрелеляем направление зума (+ или -)
    const zoomSpeed = 0.1;
    const direction = event.deltaY > 0 ? -1 : 1;
    let newScale = state.scale + (direction * zoomSpeed);

    // Ограничиваем зум (твое условие про 1см и 3см)
    // Math.min и Math.max не дают выйти за пределы
    newScale = Math.max(MIN_ZOOM, Math.min(newScale, MAX_ZOOM));

    state.scale = newScale;
    render(); // Перерисовать
}

```



*Важное дополнение (Zoom to Cursor):* В хороших стратегиях зум происходит не в центр экрана, а в точку, где стоит курсор мыши. Для этого перед изменением масштаба нужно сдвинуть `offsetX/Y` так, чтобы точка под курсором осталась на месте. Но для начала можно сделать зум просто в центр.

### 4. Техническая реализация (Рендеринг)

Есть два пути, как это отобразить в браузере.

#### Вариант А: CSS Transform (Простой, для прототипа)

Ты создаешь один большой `div` (контейнер мира), внутри которого лежат клетки. И применяешь CSS стили к этому контейнеру.

```css
.world-container {
    transform-origin: 0 0; /* Точка отсчета трансформации - левый верхний угол */
    /* Эти значения меняются через JS */
    transform: translate(offsetX px, offsetY px) scale(scale);
}

```

*Плюс:* Очень легко верстать, каждая клетка — это `<div>` или компонент Vue/React.
*Минус:* Если клеток будет 100х100 (10 000 дивов), браузер начнет тормозить.

#### Вариант Б: HTML5 Canvas (Профессиональный, для игр)

Ты не создаешь DOM-элементы. У тебя есть один тег `<canvas>`, который занимает весь экран. Ты перерисовываешь кадр 60 раз в секунду.

Алгоритм отрисовки (`drawLoop`):

1. Очистить экран (`ctx.clearRect`).
2. Сохранить контекст (`ctx.save`).
3. Применить трансформацию камеры: `ctx.translate(offsetX, offsetY)` и `ctx.scale(scale, scale)`.
4. **Оптимизация (Culling):**
* Не рисуй ВСЕ клетки мира.
* Вычисли, какие клетки сейчас видны на экране (зная `offsetX` и ширину экрана).
* Запусти цикл `for` только по видимым индексам.


```javascript
// Примерный псевдокод оптимизации
const startCol = Math.floor(-state.offsetX / TILE_SIZE);
const endCol = startCol + (screenWidth / (TILE_SIZE * state.scale));
// Рисуем только от startCol до endCol

```


5. Отрисовать линии сетки и здания.
6. Восстановить контекст (`ctx.restore`).

### Пример пересчета "см" в "пиксели"

Ты указал ограничение: *клетка не меньше 1 см и не больше 3 см*.
В веб-разработке нет точного понятия "сантиметр", так как у всех мониторов разная плотность пикселей (DPI).
Но есть стандарт: `1cm ≈ 37.8px`.

* `MIN_ZOOM`: Если базовая клетка 40px, то Scale = 1.
* `MAX_ZOOM`: Чтобы стало 3см (~120px), Scale = 3.

### Резюме для разработчика

Чтобы повторить этот интерфейс:

1. Сделай контейнер на весь экран (`width: 100vw; height: 100vh; overflow: hidden;`).
2. Внутри него "Мир", к которому применяешь CSS `transform: translate(...) scale(...)`.
3. Слушай события `wheel` (для scale) и `mousedown/move/up` (для translate) на контейнере.
4. Запрети дефолтный Drag (чтобы не выделялся текст/картинки).
