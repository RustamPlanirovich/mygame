# 🎯 ВАРИАНТЫ ПРОХОЖДЕНИЯ ИГРЫ

## ПУТЬ 1: "СТАНДАРТНОЕ ПРОХОЖДЕНИЕ" (Рекомендованный)
**Время: ~50-100 часов до первого престижа**

### Фаза 1: Пробуждение (0-2 часа)
```
1. Запуск игры
2. Прохождение туториала (если есть)
3. Строительство Generator Mk1 (стартовое здание)
4. Строительство первых шахт:
   - Miner (добыча Ore)
   - Ice Extractor (добыча Ice)
   - Carbon Harvester (добыча Carbon)
5. Накопление базовых ресурсов (Ore, Ice, Carbon)
6. Разблокировка технологии "Basic Mining" (0 RP - стартовая)
7. Разблокировка "Simple Power" (150 RP)
```

### Фаза 2: Базовая переработка (2-8 часов)
```
1. Разблокировка "Basic Processing" (250 RP)
2. Строительство Steel Smelter (Ore + Carbon → Steel)
3. Оптимизация производства:
   - Баланс добычи руды и углерода
   - Обеспечение достаточного количества энергии
4. Разблокировка "Solar Panels" (600 RP)
5. Строительство солнечных панелей для увеличения энергии
6. Первые покупки/продажи на рынке
7. Получение первых достижений
```

### Фаза 3: Индустриализация (8-24 часа)
```
1. Era 2: Индустриализация
   - Gas Exploration (1,200 RP)
   - Oil Drilling (2,000 RP)
   - Advanced Processing (2,800 RP)
2. Строительство:
   - Gas Well, Oil Well, Sand Quarry
   - Oil Refinery, Gas Refinery
   - Glass Factory, Chemical Plant
3. Plastics & Glass (4,200 RP)
4. Semiconductors (5,500 RP)
5. Первый контакт с врагами (базовые: Scout, Swarmer)
6. Строительство первых оборонительных турелей
```

### Фаза 4: Электроника (24-72 часа)

## ПУТЬ 2: "СПИДРАН" (Быстрое прохождение до первого престижа)
**Время: ~15-30 часов**

### Стратегия:
```
1. ФОКУС: Максимальная эффективность производства
2. Минимум разнообразия зданий - только критически важные
3. Агрессивная торговля для накопления Credits
4. Пропуск необязательных технологий
5. Игнорирование большинства побочных механик

Приоритетный путь технологий:
Basic Mining → Simple Power → Basic Processing → 
Solar Panels → Gas Exploration → Semiconductors →
Microchips → Computers → Rocket Science → 
Spaceships → First Colony

Ключевые здания (минимальный набор):
- Generator/Solar Panel (энергия)
- Miner, Carbon Harvester (базовые ресурсы)
- Steel Smelter (сталь)
- Semiconductor Factory (полупроводники)
- Computer Factory (компьютеры)
- Rocket Factory (ракеты)
- Spaceship Factory (корабли)
```
